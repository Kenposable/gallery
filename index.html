For the site owner

Owner sign-in

Your site is saved in your GitHub repository. Signing in with a GitHub access token lets this browser add and edit work. Visitors never see these tools.

  1. Open github.com/settings/personal-access-tokens/new.
  2. Token name: gallery editing. Expiration: up to a year.
  3. Repository access: Only select repositories, then pick gallery.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate the token, copy it, and paste it below.

The token stays in this browser only. Sign in once on each device you edit from.
